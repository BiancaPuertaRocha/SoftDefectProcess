METODOLOGIA************

Passos:
 - seleção de sistemas (objetos) para estudo
 - coleta de dados
 - seleção do modelo
 - treinamento
 - contrução do modelo de ensemble
 - avaliação das métricas

Foram escolhidos dois repositórios do projeto Apache Commons pois eles possuem uma base de código
substancial e também bastante dados históricos. A variedade de projetos ajuda na posterior generalização do modelo construido.

A coleta de dados envolve a coleção das metricas do histórico de desenvolvimento de cada sistema selecionado
Construindo o proprio dataset, nos garntimos que o conteudo é bem adaptado as necessidades da pesquisa, abragente e preciso.
Metricas foram selecionadas com informações relevantes:
 - numero de autories
 - idade do arquivo (tempo de vida)
 - numero de modificações
 - tamanho
 - linhas
 - linhas adicionadas
 - linhas deletadas
Foram selecionadas para ajudar a entender fatores que contribuem para a ocorrência de defeitos nos systemas do Apache Commons: dinamica
do time, evolução do código, atividades de manutenção, complexidade etc
Para a variavel target, foi usado o SZZ algoritmo para determinar se é defeituoso ou nao

https://doi.org/10.1145/3340482.334274
Os projetos foram analisados separamente, ou seja, como datasets separados

A seleção do modelo envolve identificar e selecionar o melhor modelo para os objetivos da pesquisa
Seleção dos modelos baseados em análise da literatura

O processo de treinamento envolve o processo iteratico de refinar o modelo usando dados de treinamento
Iterando as atividades:
 - pre processamento
 - cross validation
 - treinamento do modelo 
 - avaliação do modelo

A contrução do modelo de ensemble envolve a integração de multiplos modelos para melhorar a acurácia 
e robustes das predições
Modelo de ensemble foi construido usando tecnica de votação e os modelos individuais foram:  CART, KNN, LDA, LR, NB,
RF, and SVM. 
O estimador base foi selecionado (dentre os candidatos citados)
O tipo de votação foi selecionado (hard ou soft)
Os modelos foram treinados usando os dados ja pré processados e os passos citados na seção de treinamento
Foram utilizadas as metricas ja citadas para a avaliação

Por fim, a avaliação das métricas envolve usar as métricas correras para medir a performance dos modelos
e validar o que foi encontrado na pesquisa
