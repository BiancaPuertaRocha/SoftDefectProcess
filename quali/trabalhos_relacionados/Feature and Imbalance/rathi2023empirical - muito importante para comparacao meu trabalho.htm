Empirical evaluation of the performance of data sampling and feature selection techniques for software fault prediction

Author links open overlay panel, , , , ,
https://doi.org/10.1016/j.eswa.2023.119806Get rights and content

Abstract

Context:

The application of Software Fault Prediction (SFP) in the software development life cycle to predict the faulty class at the early stage has piqued the interest of various scholars. In the SFP domain, during research analysis, it got realized that there has been very little work instigated on addressing both class imbalance and feature redundancy problems jointly to enhance the performance and prediction accuracy of SFP models. It has been perceived in the literature survey the study of droughts with the comprehensive comparative analysis of different sampling and feature selection strategies together.

Objective:

This research builds an extensive assessment of distinct combinations of different feature selection and sampling approaches, to effectively overcome the problems of class overlap, class imbalance, and feature redundancy. The objective is to determine the best combination that will produce results with a higher degree of accuracy and an effective SFP model.

Method:

Considering the above erudition, the study has applied 8 different sampling techniques along with 10 feature selection algorithms against 56 open-source projects. The comparative analysis is performed against 5346 variants of input datasets by applying 8 different classifiers to predict the faulty class. In addition, the research paper presents an intensive assessment and performance of these techniques individually against all the input projects. We have considered accuracy and Area Under the ROC (receiver operating characteristic curve) Curve (AUC) performance metrics to compare the performance of different models developed using the classification algorithm.

Result:

For each project in the proposed work, we evaluated a total of 792 combinations that were produced using 10 feature selection methods, 1 all metrics dataset, 8 sampling methods, 1 original, unsampled dataset, and 8 classifiers. The empirical result indicates that, against 21 projects out of 54 projects, Synthetic Minority Over Sampling Technique Edited (SMOTEE) with correlation-based feature selection (FS2) combination outperformed with the highest AUC value which is 38.89 % of projects. Additionally, according to experimental results, the highest AUC values were attained by 24.07 % of projects using the SMOTEE, FS2, and RF combination.

Conclusion:

The results of the statical analysis test reveal that 93.42 % of the combinational pairs of different sampling and feature selection approaches demonstrated a significant variance in the performance of the distinct combinations of sampling and feature selection techniques. The empirical result indicates the performance of the SFP Model is adversely impacted by class imbalance and irrelevance. The outcome indicates for more than 75% of projects, the performance of trained models improved with an AUC value between a range of 0.805 to 0.99 post-application of sampling and feature selection strategies, in comparison without the use of feature selection and sampling techniques.

Introduction

Software quality is an important facet of maintaining software consistency for organizations. Preserving software consistency in terms of software quality becomes essential as well as challenging; during the scale of a software system, the size and complexity of software increases, which engenders more faults. Furthermore, the faults existing in the software system affect the quality and dependability of the software. Faults are considered an overhead for the system and most organizations and companies want to predict the defects in the code or identify fault-prone modules in the early stage of software development systems (Menzies et al., 2010). Even minor faults can lead to erroneous outputs and unexpected behavior of the program, thus leading to the failure of the project. To be in line with the software engineer’s principal goal, to deliver and ensure error-free software to end-users, the software must be tested properly (Menzies et al., 2010). Several ways of detecting faults in the early stages of software development have been presented by researchers in the past (Singh & Malhotra, 2012). Learning signposts detection of faults in early-stage helps to control quality, manage delivery timelines and minimize post-production bugs, thereby allowing for on-time distribution to customers. The common use case among all researchers and the software community is software fault prediction to identify whether a module is defective or not by using Data Mining (DM) and Machine Learning (ML) techniques (Bhandari, Kumar, & Sangal, 2021).

The DM and ML techniques can help in predicting whether a class is bug-prone or not, which will help the software engineers to give more attention to bug-prone modules and thus saving a lot of time and cost. Optimization in time & cost will lead to minimizing the software maintenance outlay and an increase in customer satisfaction. In this paper, we employed the eight most prominent machine learning classifiers as suggested by several researchers (Lessmann et al., 2008, Pandey et al., 2021, Son et al., 2019) in the domain of Software Fault Prediction using ML. The Gaussian Naïve Bayes (GNB), Logistic Regression (LOGR), Decision Tree (DT), Random Forest (RF), Support Vector Machine (SVM) with radial basis function kernel function (SVCR), SVM with linear kernel function (SVCL), Bagging (BAG), and AdaBoost (ADAB) has been employed to train Software Fault Prediction (SFP) model and predict the faulty class in the datasets. All of the chosen classification techniques are tested against 54 open-source object-oriented projects.

Object-oriented software methodologies are widely used in software development. Software metrics are used for developing fault prediction models, their performance will also depend on these source code metrics (Basili et al., 1996, Chidamber and Kemerer, 1994). Hence, selecting proper subsets of software metrics will affect the overall performance of the prediction model (Rathore & Gupta, 2014). One of the purposes of this study is to identify the impact of feature selection methods on fault predictability. The performance of the SFP models depends on these metrics; it is essential to identify the right set of metrics to optimize the performance of implemented models to detect faulty classes. Thus, in this paper, we have applied five feature ranking and five feature subset selection techniques over a variety of datasets to identify the best software metrics/features that are useful to train the SFP models.

The input dataset contains a varied distribution of instances, majority and minority samples, etc., hence, it impacts the performance of SFP models. As a result, the training dataset’s nature influences the classifier’s performance (Elahi, Kanwal, & Asif, 2020). Generally, in software project metrics, the number of non-faulty cases outnumbers the number of defective cases, resulting in a class-imbalanced challenge in SFP models. SFP models trained on these class-imbalanced datasets may favor non-defective examples while misclassifying defective ones (Pak, Wang, & Su, 2018). After these training datasets have been balanced, the developed SFP models may achieve good prediction performance (Gong et al., 2019, Tantithamthavorn et al., 2018). Consequently, the problem of class imbalance is one of the major variables impacting the performance of SFP models, and a growing number of researchers are striving to overcome it. Another objective of this paper is to tackle the class imbalance problem, which can impede the SFP model’s performance. Thus, before applying the feature selection techniques we balance the datasets using eight different sampling methods to solve the class imbalance problem.

Our research analysis in the field of SFP divulges there have been very few studies (Joon et al., 2020, Pandey and Tripathi, 2021, Yohannese and Li, 2017) conducted against addressing both class imbalance and feature redundancy problems collectively to improve the performance and prediction accuracy of the SFP model. Yohannese and Li (2017) engaged SMOTE Sampling technique and Correlation-based feature selection (CFS), Principal Component Analysis (PCA), & Information Gain (IG) feature selection techniques in their study. Joon et al. (2020) employed the SMOTETomek sampling technique and simple majority voting feature selection. In the study performed by Pandey and Tripathi (2021), evaluated sampling techniques are random undersampling, class balancer, SMOTE, & Spread Subsample Technique, they also employed the information gain feature selection technique. However, the above-mentioned study work does not include thorough experimentation of a combination of various sampling procedures and feature selection techniques on the performance of SFP models. Additionally, limited datasets (mostly on an average of 4 to 6) were used for the experiments in the previous studies that combined sampling and feature selection techniques.

It is necessary to determine whether the combined approach significantly improves the performance and accuracy of the developed SFP model because the implementation of the sampling and feature selection approach will also increase complexity, this paper analyses the performance of the developed SFP model with/without feature selection and sampling approaches. This paper conducts extensive experimentation to identify the best-performing combination to optimize the implementation cost and efficacy of the developed SFP model. Thus, we have applied 10 feature selections + 1 all feature metric, 8 sampling techniques + 1 original dataset, and 8 classifiers, against 54 different projects holding a different percentage of faulty classes. The main goal of this study is to jointly address the class imbalance and feature redundancy issues, as well as to draw a general conclusion regarding the best-performing combination, and optimize, and enhance the outcomes of the proposed SFP model over others.

Our major contributions to the paper are as follows:

  • •

    We are the first to thoroughly examine the combined approach with 99 different combinations of feature selection and sampling techniques jointly ((10 Feature selection + 1 All metrics) * (8 sampling approaches + 1 original/unsampled dataset)) against 54 open-source datasets, with the employment of 8 well-known classifiers, to draw a generalized conclusion on the most efficient combination

  • •

    We carried out the statical analysis test to verify the performance difference of various combinations of feature selection and sampling techniques

  • •

    As the implementation of the sampling and feature selection approach will also increase complexity, we compare the performance of the developed SFP model with/without feature selection and sampling approaches to determine whether the combined approach significantly improves the performance and accuracy of the developed SFP models

The respective Research Questions (RQs) and their sub questions are justified in this study:

The primary RQ: What effect do the use of different combinations of feature selection and sampling approaches have on the performance of the developed SFP model? A total of 54 open-source datasets were used in this study, and 99 unique combinations were examined using 10 feature selection methods, 1 all metrics dataset, 8 sampling methods, and 1 original i.e. unsampled dataset, by employing 8 classifiers. The study evaluated the efficacy of the built models and determined the overall top-performing combinations.

The corresponding sub-questions are:

  • •

    RQ1: Is the outcome of feature-ranking and feature-subset selection strategies statistically equivalent? We carried out extensive experimentation of 5 feature ranking and 5 feature subset selection methods and 1 All feature metrics against 54 open-source object-oriented datasets in this study to draw general conclusions and determine the best-performing feature selection approach individually.

  • •

    RQ2: How powerful are the various feature selection methods in terms of optimizing the performance of the SFP model ? In this study, we have investigated the performance of 11 feature selections (1 for all feature metrics) with a combination of 8 sampling algorithms and 1 unsampled i.e. original dataset against 54 open-source datasets.

  • •

    RQ3: Which sampling method gives efficient and effective performance? In order to reach a general conclusion about the sampling method that performs the best overall, we employed 8 sampling methods and tested their effectiveness with the original dataset against 54 input datasets.

  • •

    RQ4: What is the impact of sampling techniques on the predictability of SFP models? The study examines how well a set of eight classifiers and nine sampling techniques performs together (1 unsampled or original dataset).

  • •

    RQ5: What effect do different classifiers have on predicting faulty source code? The paper investigates and validates whether the performance of eight classifiers produces the same outcome with all employed combinations of feature selection and sampling techniques.

  • •

    RQ6: Is the outcome of various feature selection methods combined with different sampling techniques statistically equivalent? In the proposed research work, we have examined the utilized feature selection methods after combining 8 sampling approaches and 1 unsampled dataset performance.

In addition, to ensure fair predictions, the study conducts statistical analysis of the engendered software fault prediction models. The performance and reliability of these models were evaluated using the performance parameters: accuracy and AUC.

    • A software defect prediction method based on learnable three-line hybrid feature fusion

      2024, Expert Systems with Applications

      Software defect prediction (SDP) plays a crucial role in ensuring the security and quality of software systems. However, it faces challenges posed by high-dimensional features present in software defect datasets and the limited effectiveness of traditional nonlinear dimensionality reduction methods in extracting essential feature information. To address these issues, we propose a novel approach called learnable three-line hybrid feature fusion (LTHFFA), which incorporates the principle of three-line hybrid breeding into feature fusion for the first time. In this method, three distinct dimensionality reduction techniques are initially employed to obtain three separate sets of features. Subsequently, a learnable weight factor feature fusion method is proposed to facilitate automatically learn and dynamically update of feature weights. By integrating the three feature sets based on the principle of three-line hybrid breeding, we derive learnable three-line hybrid fusion features. These features are then utilized in the context of software defect prediction. Experimental results demonstrate the superior performance of LTHFFA compared to nine other dimensionality reduction methods across seventeen publicly available software defect datasets. LTHFFA exhibits the ability to effectively integrate multiple feature sets, reduce feature redundancy, and enhance predictive accuracy. Moreover, statistical analysis using Friedman ranking and Holm's post-hoc test confirms the significant advantage of LTHFFA over alternative dimensionality reduction methods.
